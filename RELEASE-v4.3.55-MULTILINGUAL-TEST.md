# KoW Companion Multilingual v4.3.55 — TEST

## Merge basis
This build uses English v4.3.55 LIVE as the functional master and restores the multilingual framework from the working v4.3.36 multilingual build.

## English v4.3.55 features now included
- Central Inventory shared throughout the app.
- Legendary Officer Badge Chest and Legendary Officer Badge Selection Chest resources.
- ORV/SRV and Universal Badge inventory.
- Elite/Epic/Legendary Stars and XP Books.
- Individual Officer Badge inventory for all supported Officers.
- All / Elite / Epic / Legendary Officer Badge filters.
- Clean Officer names without rarity suffixes.
- Inventory moved left in navigation.
- Single-row, larger, full-width navigation with horizontal scrolling on narrow screens.
- Multi-Officer Planner reads held Individual Officer Badges.
- Planner uses saved Officer progress.
- MAXED Officers require 0 additional badges and receive no shared allocation.
- Correct Fully Funded / Partially Funded / Shortfall / MAXED status logic.
- Original Officers do not use ORV.
- Planner remains preview-only and does not consume Inventory.

## Multilingual framework retained
- English
- French
- German
- Italian
- Saved language selection.
- Existing translated language packs and translated user guides retained.

## Translation testing note
New v4.3.55 interface text that did not exist in v4.3.36 may initially fall back to English until its French/German/Italian translation entry is added. Existing translations remain active and should not bleed between languages.

This is a TEST build and should be verified before replacing the multilingual live build.
