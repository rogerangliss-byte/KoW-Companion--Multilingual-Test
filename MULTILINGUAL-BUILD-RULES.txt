KoW Companion v4.6.0 — Multilingual Build Rules

SINGLE SOURCE OF TRUTH
----------------------
KoW-Companion-English-v4.6.0-STABLE.zip is the complete functional application.

PERMITTED MULTILINGUAL DIFFERENCES ONLY
---------------------------------------
1. CNAME = multilingualtest.firestorm-companion.uk
2. Multilingual-Test service-worker cache namespace
3. /lang presentation-only dictionaries, translated Help, language selector and QA
4. One final bootstrap <script> immediately before </body>
5. Multilingual TEST identity/banner
6. English-Live-only release note may be omitted

FORBIDDEN
---------
- No Multilingual copy/rewrite of Officer Edit, MAX Officer, strands, Stars, XP,
  Inventory, Planner, Database, Progress, Releases, calculations, persistence,
  save/load, forecasting, backup/restore or any other application function.
- No Multilingual MutationObserver over application controls.
- No Multilingual dispatchEvent/click automation into application functionality.
- No duplicate MAX implementation.
- No functional patch may be made only in Multilingual.
Any functional correction must be made in English Stable/Test first, validated there,
then inherited unchanged by Multilingual.

QA8 RULE:
Language QA is read-only and may not click controls, dispatch events, change form values, or invoke application functions.

PERMANENT ROBUST LANGUAGE QA RELEASE GATE
QA11 or later is mandatory before every Multilingual Live promotion. It must check rendered English bleed, EN→FR/DE/IT unchanged text, dynamic-source translation coverage, dictionary quality, Help and the EN/FR/DE/IT selector. A generic/lightweight QA PASS is not sufficient. Functional code remains inherited from English Stable.

QA12 REPORT-DRIVEN CLOSURE
Every returned robust QA JSON is the authoritative translation defect list. All FR/DE/IT FAIL findings must be closed or explicitly classified as proper nouns/game terminology before Live. Robust QA may not be weakened to obtain PASS.


PERMANENT USER GUIDE READABILITY RULE (QA13B+)
- In French, German and Italian, the ENTIRE in-app User Guide must render over a continuous opaque black reading surface.
- No User Guide heading, paragraph, list item, notice or explanatory text may render directly over the tank background image.
- This applies on desktop, tablet and mobile.
- Language QA must treat loss of this black reading surface as a release-blocking presentation failure.
