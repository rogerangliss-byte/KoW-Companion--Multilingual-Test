# QA Report Download Restored

A `Download QA Report` button is restored next to `Run Full Rendered QA`.

The JSON report includes:
- English/French/German/Italian PASS/FAIL
- Dictionary issue counts
- Rendered English bleed counts
- Full User Guide failure counts
- Pop-up failure counts
- Expanded failure lines/details where available
- selected language, timestamp, URL and TEST-banner detection

This is now part of the Multilingual QA feature set.
