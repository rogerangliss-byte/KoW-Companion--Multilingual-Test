# KoW Companion Multilingual v4.3.57 — TEST

## Translation Audit QA build

Adds a TEST-only Translation Audit in Settings. It checks dictionary coverage, identical-to-English entries and rendered English remnants, with approved exclusions for Officer names, abbreviations, season codes and numbers. The report can be exported as a text file.

No calculation, Officer database, inventory, progress, forecast or gameplay-resource logic was intentionally changed.
